
# Open Resume

A fully client-side, privacy-first Resume Builder built with React, TypeScript, and Tailwind CSS.

## Features
- **Privacy First**: All data is stored in `sessionStorage` and never leaves your browser.
- **Multilingual**: Native support for English (LTR) and Persian (RTL).
- **Multiple Templates**: Choose between Minimal, Modern, and Creative layouts.
- **High-Quality Export**: Export to PDF (A4) or standalone HTML.
- **Responsive Design**: Works great on Desktop and Mobile.
- **Dynamic Content**: Add/Remove sections easily.

## Tech Stack
- **Framework**: React 18+
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **PDF Engine**: html2pdf.js
- **Fonts**: Inter (EN), Vazirmatn (FA)

## Local Development
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the development server.
